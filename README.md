### 🚀 Featured project

**🌬️ Room CO₂ monitor on the desktop** (2025)<br/>
An Arduino Nano reads CO₂, temperature and humidity from a Sensirion **SCD41** over I²C, and a Python service turns the GNOME wallpaper into a hand-drawn isometric room whose **door opens wider as the air gets worse** — with live outdoor weather in the doorway. No 3D engine: custom isometric projection, painter's algorithm, and hysteresis so the door doesn't flap.

`Arduino Nano` `SCD41 · I²C` `Python` `Cairo · Pango` `GNOME` `systemd` `Open-Meteo`

👉 Interactive walkthrough on my [portfolio](https://portfoglio-six.vercel.app)
